# Personal Portfolio

## Description

This project is a responsive personal portfolio website built from scratch.

## Technologies

- HTML5
- CSS3
- JavaScript ES6+
- Git

## Sections

- About Me
- Skills
- Projects
- Contact

## Features

- Responsive layout
- Flexbox
- CSS Grid
- Mobile media queries
- Interactive theme switcher

## JavaScript Feature

The website includes a theme switcher.

When the user clicks the theme button, a JavaScript click event is triggered.
The callback function toggles the `dark-theme` class on the body element.
CSS then applies the dark theme styles.
